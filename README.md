# DSH 模型预设

为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web GUI 提供可自定义的**模型预设**：每个预设保存一个模型（可选推理强度），按顺序编号为「预设模型 1、2、3…」，地位相同，可随时添加、删除。点击输入框里的按钮打开配置，按快捷键切换当前对话使用的模型。

输入框只增加一个 **模型预设** 按钮，不并排放置多个控件。

## 功能

- 预设不再区分规划模型和执行模型；每一条都是同一种「预设模型 N」。
- 预设可逐项添加、删除，数量不限，但至少保留一条。
- 每个预设分别保存模型与可选的推理强度；模型与推理强度在同一行显示，不预设供应商或模型名称。
- 点击输入框里的 **模型预设** 按钮直接打开配置窗口，不再弹出中间菜单；切换模型使用快捷键。
- 按钮在当前选择匹配预设时显示该预设名称（例如「预设模型 2」）；否则显示「模型预设」。若多个预设内容完全相同，按顺序取第一个。
- 删除某条预设后，其余预设按顺序重新编号，已配置的模型和推理强度保留。
- 复用 DSH 模型目录和选择接口，原有模型选择器与 `/model` 仍可正常使用。
- 失效模型、失效推理强度、配置冲突与切换失败会提示，不自动改选其他模型。
- 配置窗口里每个预设的模型、推理强度右侧各有「团队协作」下拉框（未设置 / 开启 / 关闭），与模型一起保存；切换预设时同时应用该预设记录的团队协作状态，「未设置」表示切换时不动团队开关。当前 DSH 未提供该能力或会话不支持切换时，下拉框不显示或提示失败后保持窗口打开。

**切换模型、推理强度和已记录的智能体团队协作开关，不切换规划模式或文件权限，不发送聊天消息，不自动规划或执行任务。**

## 安装

前提：已安装并配置 DSH，Web GUI 能正常列出至少一个可用模型。

### 用包名安装（npm）

在侧边栏 **插件 → 添加插件** 输入：

```text
dsh-model-roles
```

也可通过终端安装到 `web` profile：

```bash
dsh plugin --profile web add dsh-model-roles
```

### 从 GitHub 安装

在侧边栏 **插件 → 添加插件** 输入：

```text
https://github.com/qinpegnsen/dsh-model-roles.git
```

安装完成后启用插件。终端安装：

```bash
dsh plugin --profile web add https://github.com/qinpegnsen/dsh-model-roles.git
```

若使用其他 profile，请替换 `web`。仓库与 npm 包均包含构建产物，普通安装无需先构建，也无需另开 Web 服务器。

安装并启用后刷新 GUI，再打开一个普通对话，在输入框工具栏「权限」控件旁寻找 **模型预设** 按钮。若看不到，先在插件页核对启用状态，再刷新页面。

### 从源码本地安装

```bash
git clone https://github.com/qinpegnsen/dsh-model-roles.git
cd dsh-model-roles
npm run build
npm test
dsh plugin --profile web add "$PWD"
```

PowerShell 下最后一行可用：

```powershell
dsh plugin --profile web add (Get-Location).Path
```

构建和单元测试使用 Node.js 自带模块，不需要运行 `npm install`。React、UI 组件和模型服务由 DSH 在运行时提供。

## 使用

1. 点击输入框中的 **模型预设** 按钮，直接打开配置窗口。
2. 每条预设单独设置模型；如果该模型提供推理强度，可在同一行选择。需要更多预设时点 **添加预设模型**，不需要的点 **删除**（只剩一条时删除按钮不可用）。需要该预设附带开启「启用智能体团队协作」时，把同一行右侧的下拉框选成 **团队协作 · 开启**（想明确关掉就选 **关闭**，保持不干预就留在 **未设置**），然后点击 **保存**。未保存时点 **取消** 不会修改现有配置。
3. 用快捷键切换：预设模型 N 的默认键位见下表。
4. 按钮上显示当前命中的预设名称（例如「预设模型 1」），鼠标悬停可看完整模型名。以 DSH 原有模型选择器显示的模型名称为准；切换从下一次模型请求开始生效，已经运行中的步骤不改变。

未配置预设时只提示先配置，不替你选择模型。要清除某条预设，在配置窗口把该行模型选成「未配置」后保存；整行不需要时直接删除。

### 默认快捷键

| 预设 | Windows / Linux | macOS |
| --- | --- | --- |
| 预设模型 1 … 9 | `Ctrl + Alt + 1` … `Ctrl + Alt + 9` | `⌘ + ⌥ + 1` … `⌘ + ⌥ + 9` |
| 预设模型 10 | `Ctrl + Alt + 0` | `⌘ + ⌥ + 0` |
| 预设模型 11 及以后 | 默认不绑定 | 默认不绑定 |

Linux 的默认键位声明同 Windows；实际拦截由浏览器与桌面环境决定。在 **设置 → 编辑快捷键** 搜索「预设模型」，可修改或清除绑定；已自定义的绑定优先于默认值。0.3.0 起快捷键作用于「预设模型 N」，0.2.x 针对「规划模型／执行模型」保存的自定义绑定不再沿用。

Web 中快捷键面向当前主对话，不在终端、非对话面板或模态窗口中切换模型。DSH Desktop 的键盘拦截策略由宿主控制；本版本未进行 Desktop 实机验证。

## 配置与隐私

预设只保存在当前浏览器、当前 DSH 地址的 `localStorage`：

```text
dsh.model-roles.v1
```

只包含提供方 ID、模型 ID、可选的推理强度、预设的排列顺序，以及各预设是否启用智能体团队协作；不保存密码、API Key、账号登录态或聊天内容。配置不会跨设备同步。不同标签页读取同一份配置；保存前会检查配置是否已被其他窗口修改。

0.1.x、0.2.x 写入的「规划模型 + 执行模型」配置会在读取时自动迁移：规划模型变成「预设模型 1」，执行模型 1、2…依次变成「预设模型 2、3…」，已记录的团队协作开关跟着对应预设走，不额外添加或丢弃预设。新保存的数据使用版本 4 格式。

插件本身不新增网络请求或遥测。模型目录读取和模型切换由已有的 DSH 服务完成。

## 兼容性与验证范围

- 当前已核验的 DSH 版本：**0.2.0-rc.2**。
- 依赖 DSH 的 `modelDirectories`、`shortcuts`、`slots`、会话服务及共享 UI 组件；其他 DSH 版本尚未验证。
- **macOS Chrome Web GUI** 已实测 0.1.0：菜单配置与保存、菜单切换、快捷键、原生模型位回显、取消不写入、刷新后配置保留。
- 0.2.0 的可增删执行模型与同行推理强度在 Windows Web GUI 中实测过配置窗口、增删、保存与切换；macOS 未重新实测。
- 0.3.0 的扁平预设列表、旧配置迁移与最后一条不可删除由单元测试覆盖；尚未在本机 Web GUI 实机验收。
- 不支持已寻址的子智能体会话。权限、模型凭据与供应商可用性仍由 DSH 管理。
- 当前单元测试覆盖配置校验与迁移、预设增删与重编号、团队协作标记随预设位置搬移与切换应用、动态快捷键注册清理、跨窗口冲突、切换互斥、无效模型拒绝、远程失败、会话生命周期，以及配置窗口与菜单的渲染契约。单元测试不替代实机 UI 验收。
- 团队协作开关依赖 DSH 内置的智能体团队能力；本机 0.2.2-rc.3 未做实机 UI 验收。

## 开发

```bash
npm run build
npm test
```

- `src/core.cjs`：预设存储与迁移、预设增删、模型校验、切换、动态快捷键。
- `src/client.cjs`：单按钮菜单、配置窗口和反馈。
- `scripts/build.mjs`：生成 DSH 客户端 factory 与无行为的宿主入口。
- `lib/`：随仓库提供的构建产物，便于直接安装。改源码后先重新构建，再一并提交产物。
- `test/*.test.cjs`：不依赖账号、网络或浏览器的单元测试。

已安装插件的源码编辑不保证自动生效。没有对应构建监听时，重建后需停用并重新启用插件，再刷新 GUI；必要时按宿主提示重启 DSH。不要为此另开替代 GUI 服务器。

## 停用

在 **插件 → 模型预设** 停用组合包，即移除单按钮菜单及快捷键。原有模型选择器继续可用；当前对话模型不随停用自动恢复。浏览器里的预设与快捷键覆盖保留，重新启用后可继续使用。

## 版本记录

- **0.3.0**：取消「规划模型／执行模型」的角色区分，统一为按顺序编号的「预设模型 1、2、3…」；每条预设地位相同、都可添加和删除（至少保留一条），快捷键依次为 `⌘/Ctrl + Alt + 1…9`、第 10 条用 `0`；旧配置自动迁移，团队协作开关跟随预设位置。
- **0.2.0**：执行模型可自定义添加和删除（数量不限）、新增「执行模型 N」预设与动态快捷键、模型与推理强度同行显示、按钮点击直接打开配置窗口（去掉中间菜单）；读取 0.1.x 配置时自动迁移。
- **0.1.0**：规划模型 + 单个执行模型的双预设、菜单与快捷键切换。
